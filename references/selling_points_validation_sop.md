# 产品卖点价值体系 vs 云图心智反射验证 SOP (Universal Mind Validation Model)

> **定位**：全车型通用的**「宣发卖点输入 ➔ 云图数据调取 ➔ 真实心智反射交叉检证 ➔ 策略修正输出」**标准作业流程。适用于任何品牌、任意车系的上市复盘、阶段营销体检与卖点有效性验证。

---

```
┌────────────────────────────────────────────────────────────────────────┐

└──────────────────────────────────┬─────────────────────────────────────┘
                                   │
┌──────────────────────────────────▼─────────────────────────────────────┐

                                   │

│ 【Step 3：检证端】五维矩阵交叉匹配 (强占领 / 突围中 / 盲点哑炮 / 负面 / 自发)│

```

## 二、 五维心智交叉检证矩阵 (The 5-Category Matrix)

AI 在获取用户输入的卖点体系与云图 TOP50 心智词后，自动归类至以下 5 大象限进行穿透诊断：

```
                              用户态度 (美誉度 / 情感正负)
                                            ▲
                                            │
               【🌟 强占领区】                │             【📈 突围攀升区】
     • 官方主推核心卖点                      │   • 新进榜 / 排名大幅上升 (↑10+)
     • 稳居 TOP 10 高位                      │   • 正向美誉度较高
     • 美誉度高 (≥20%)                      │   • 属于成长型爆发卖点
     • 策略：保持声量，作为第一沟通锚点        │   • 策略：追加投流（种草通/达人加码）
                                            │
   ─────────────────────────────────────────┼─────────────────────────────────────────► 认知深度 (云图 TOP50 排名)
                                            │
               【🚨 口碑风险区】              │             【⚠️ 盲点 / 哑炮区】
     • 进入 TOP 50 讨论                     │   • 官方宣发重推，但【未进入 TOP 50】
     • 但美誉度为负或偏低 (≤0%)              │   • 用户讨论极少，认知完全未破圈
     • 存在用户顾虑 / 槽点 / 竞品攻击         │   • 策略：判定为无效卖点，停止硬推或
     • 策略：专项公关科普 + 针对性打消顾虑    │           彻底重构场景化话术
                                            │
                                            ▼
```

### 矩阵诊断定义与判定标准：

| 象限类别 | 判定标准 | 典型特征 | 营销策略对策 |
|---|---|---|---|
| **🌟 强占领区 (Validated)** | 属于官方主推卖点 + 稳居 TOP 1~10 + 美誉度 ≥20% | 用户高度认可，品牌护城河 | **保持宣发主线**，作为所有物料与达人合作的第一核心支点 |
| **📈 突围攀升区 (Rising)** | 属于主推卖点 + 本月新进榜 (New) 或排名上升 ≥10 位 | 投放正在见效，心智快速成型 | **重点加码投流**（星图质爆文/种草通加热），趁势打透该卖点 |
| **⚠️ 心智盲点区 (Blindspots)** | 官方重推卖点，但 **未进入 TOP 50 讨论** | 用户感知极低，宣发沦为自嗨 | **立即调整/止损**：若非核心体验则砍掉宣发预算；若属核心技术则必须重构场景化通俗语言 |
| **🚨 口碑风险区 (Risk)** | 进入 TOP 50 + 美誉度 ≤0% 或负向争议突出 | 关注度高但存在质量/续航/价格顾虑 | **公关/测评介入**：安排垂直硬核车评人实测拆解，打消潜在顾虑 |
| **💡 自发破圈区 (Unprompted)** | **官方未主推**，但用户自发讨论冲进 TOP 30 | 用户真实痛点或意外出圈点 | **反哺官方叙事**：将用户自发点纳入下一阶段官方传播矩阵 |

## 三、 用户输入与输出标准化模板 (Input & Output Templates)

### 3.1 用户的标准输入格式 (User Prompt Input)

用户在会话中只需提供车型与该车型的卖点体系（维度与数量不限）：

```markdown
【车型名称】：传祺向往 S7 (或任意车型)
【分析周期】：上市后近 30 天
【主推卖点价值体系】：
1. 空间维度：2.9米大轴距、同级最大后备箱、二排纯平地板
2. 舒适座舱：双阀SDC电磁悬架、全感官智能防晕车系统、无风感空调
3. 动力续航：全新插混系统、CLTC 248km纯电续航、电四驱模式
4. 安全保障：360°气囊矩阵、神盾电池安全系统
5. 科技外观：14种交互灯语、三排电动无级滑轨
```
